video, **không phải tốc độ TTS trong app**. Theo yêu cầu, tệp MP4 này được giữ
trong bộ bàn giao Git cùng hướng dẫn, không bỏ qua bằng `.gitignore`.
Bản public này giữ video tại liên kết tương đối bên trên.
