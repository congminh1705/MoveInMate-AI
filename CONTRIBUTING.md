# Contributing

Create a feature branch and describe the user-facing change and relevant validation in your pull request. Use synthetic fixtures and a separate PostgreSQL test database.

Run the checks described in README.md for the code you change. Do not commit API keys, passwords, resident records, document uploads, database dumps, private prompts or machine-specific configuration. Keep attribution and third-party license notices.

This public copy does not install prompt-collection hooks. CI runs manually until the repository owner chooses to enable automatic triggers.

Report security issues privately as described in SECURITY.md. Follow CODE_OF_CONDUCT.md.
